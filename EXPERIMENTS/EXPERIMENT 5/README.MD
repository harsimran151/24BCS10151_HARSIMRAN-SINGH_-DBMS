# Experiment 5: SQL Queries and Conditional Statements

## Objective

To understand and implement SQL queries involving aggregate functions, conditional expressions, string functions, and procedural conditional statements using PostgreSQL.

---

## Programs

### 5.1 Calculate American Cuisine Revenue Percentage

**Aim:** Find out what percentage of the total revenue is contributed by American Cuisine and round the final value to 2 decimal places.

```sql
SELECT ROUND((100 * SUM(CASE WHEN cuisine = 'American' THEN price ELSE 0 END)) / SUM(price), 2)
AS American_Revenue
FROM Orders;
```

**Output:**

```text
American_Revenue
----------------
27.75
```

This query uses `SUM()`, `CASE WHEN`, and `ROUND()` to calculate the percentage of total revenue generated by American Cuisine.

### 5.2 Find Invalid Tweets

**Aim:** Retrieve the `tweet_id` of tweets whose content contains more than 15 characters.

```sql
SELECT tweet_id
FROM Tweets
WHERE LENGTH(content) > 15;
```

This query uses the `LENGTH()` function to determine the number of characters in the tweet content and filters tweets having more than 15 characters.

### 5.3 IF-ELSE Conditional Statement in PostgreSQL

**Aim:** Use an `IF-ELSIF-ELSE` statement to determine the range of a given integer value and display an appropriate notice.

```sql
DO $$
DECLARE
    VAL INT := 21;
BEGIN
    IF VAL > 0 AND VAL <= 10 THEN
        RAISE NOTICE 'Your value is % and range is between 1 to 10', VAL;

    ELSIF VAL > 10 AND VAL < 20 THEN
        RAISE NOTICE 'Your value is % and range is between 11 to 20', VAL;

    ELSE
        RAISE NOTICE 'YOUR value is % and range is greater than 20', VAL;

    END IF;
END;
$$
```

**Output:**

```text
NOTICE: YOUR value is 21 and range is greater than 20
```

The program declares an integer variable, checks its value using `IF`, `ELSIF`, and `ELSE`, and displays the corresponding message using `RAISE NOTICE`.
